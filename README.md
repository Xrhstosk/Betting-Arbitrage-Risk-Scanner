# 🎯 Αυτοματοποιημένος Σαρωτής Αποδόσεων & Ασύμμετρου Ρίσκου (Sports Betting Scanner)

Ένα αυτοματοποιημένο σύστημα συλλογής και ανάλυσης αθλητικών αποδόσεων σε **Python** και **PostgreSQL**, το οποίο σαρώνει σε πραγματικό χρόνο διεθνείς αγορές, εντοπίζει ευκαιρίες χαμηλού περιθωρίου κέρδους (Low Margin / Asymmetric Risk), υπολογίζει τη βέλτιστη κατανομή πονταρίσματος και αποθηκεύει τα δεδομένα σε σχεσιακή βάση δεδομένων.

## 🚀 Τι κάνει το Project

1. **Αντλεί ζωντανά δεδομένα:** Επικοινωνεί μέσω REST API (*The Odds API*) και συλλέγει τις υψηλότερες διαθέσιμες αποδόσεις ανά σημείο (`1`, `X`, `2`) για όλα τα ενεργά αθλήματα (Ποδόσφαιρο, Τένις, Μπάσκετ κ.ά.), εξαιρώντας μη διαθέσιμες εταιρείες μέσω λίστας αποκλεισμού (Blacklist).
2. **Υπολογίζει το Ρίσκο και τα Stakes:**
   * **Αγορές 3 επιλογών (3-Way):** Κατανέμει ένα προκαθορισμένο budget (`100€` με στρογγυλοποίηση ανά `5€`) ώστε η ισοπαλία (`X`) να παραμένει κοντά στο μηδέν (`-2.00€` έως `+2.00€`) και το άθροισμα των άλλων δύο σημείων να δίνει καθαρό θετικό αποτέλεσμα $\ge +2.00€$.
   * **Αγορές 2 επιλογών (2-Way):** Εντοπίζει αγώνες χωρίς ισοπαλία όπου το άθροισμα των καθαρών αποδόσεων είναι $\ge +2.00€$.
3. **Αποθηκεύει στη Βάση Δεδομένων:** Καταχωρεί τους αγώνες και τα προτεινόμενα πονταρίσματα στην **PostgreSQL**, ενημερώνοντας δυναμικά τις αποδόσεις (`UPSERT`) χωρίς διπλότυπες εγγραφές.

## 🛠️ Τεχνολογίες & Βιβλιοθήκες

* **Python 3** (`requests`, `psycopg2`, `datetime`, `time`)
* **PostgreSQL & pgAdmin 4** (Σχεσιακός σχεδιασμός, Constraints, UPSERT queries)
* **The Odds API** (JSON REST API)
